# Manual de Usuario
## Descripción
[Esta práctica](/wiki/Practica-1--Diseño-y-servido-estático) busca servir una serie de páginas web estáticas para el proyecto [AI-Scribe](/wiki/AI-Scribe).

## Puesta en Marcha
El servidor se debe lanzar desde el subdirectorio P1. Puedes acceder a este desde la terminal con:

    cd /P1 

Para ejecutar el servidor desde la terminal:

    node tienda.js

## Más información
Las páginas están generadas con React.js. Para más información sobre el funcionamiento, consultar la [documentación técnica](/wiki/Practica-1--Documentación-Técnica).
